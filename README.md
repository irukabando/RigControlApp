# アマチュア無線機の制御ソフト
アマチュア無線機（Yaesu, Icom, Kenwood）の制御を GUI 上で行うことができるソフトウェアです。

## 主な機能
* 周波数の取得
* 周波数の変更
* VFO A <-> VFO B の切り替え
* バンドの変更
* モードの変更
* アンテナの変更


---

## 初めてアプリを触る人向けの `.ini` 設定解説ガイド

本アプリケーションでは、無線機（トランシーバー）のメーカーや機種ごとの違いを `.ini` ファイルを編集することで吸収し、自由自在に制御できます。

### 1. 特殊な記述（プレースホルダー・書式指定子）の意味

コマンド設定の中に現れる `{0}` や `{0:D11}` は、プログラムが状況に応じた数値やコードを動的に差し込むための「変数枠」です。

| 記述 | 意味 | 具体例 |
| --- | --- | --- |
| **`{0}`** | パラメータをそのまま文字列として埋め込みます。 | `MD_SET = MD{0};` でモードコードが `2` の場合 → `MD2;` が送信される |
| **`{0:D3}`** | 整数を「**3桁の10進数・ゼロ埋め**」で埋め込みます。 | AFゲインが `15` の場合 → `AG0015;` |
| **`{0:D8}`** | 整数を「**8桁・ゼロ埋め**」で埋め込みます。 | 7.074MHz（7,074,000Hz）の場合 → `07074000` |
| **`{0:D11}`** | 整数を「**11桁・ゼロ埋め**」で埋め込みます（Kenwood/Yaesu ASCIIの周波数形式）。 | 14.074MHz（14,074,000Hz）の場合 → `00014074000` |

### 2. セクション別 設定項目の詳細解説

#### `[SERIAL]`（シリアル通信設定）

PCと無線機を接続するUSB/COMポートの電気的・通信的な基本設定を行います。**無線機本体のMENU設定と完全に一致させる必要があります。**

| 項目名 | 設定可能な値 | 設定の基準・何に効く設定か |
| --- | --- | --- |
| **`PortName`** | `COM1`, `COM3` など | PCの「デバイスマネージャー」で認識されているポート番号。画面側のUIでも選択可能。 |
| **`BaudRate`** | `4800`, `9600`, `19200`, `38400`, `115200` 等 | 通信速度（bps）。無線機のCAT/CI-Vレート設定と合わせます。高いほどレスポンスが速くなります。 |
| **`DataBits`** | `8`（一般的）, `7` | 1データ文字あたりのビット数。通常は `8` です。 |
| **`Parity`** | `None`, `Even`, `Odd` | 誤り検出符号。通常は `None`（なし）です。 |
| **`StopBits`** | `One`（1ビット）, `Two`（2ビット） | データの終了を示すビット長。通常は `One` または `Two`。 |
| **`DtrEnable`** | `True`, `False` | DTR（データ端末レディ）信号ピンの電圧制御。USBシリアル変換ICの電源供給やPTT制御に関わります。 |
| **`RtsEnable`** | `True`, `False` | RTS（送信要求）信号ピンの電圧制御。CTS/RTSフロー制御やPTT制御に関わります。 |
| **`ReadTimeoutMs`** | ミリ秒（例: `1000`） | 受信タイムアウト時間。無線機からの返信を待つ上限時間です。 |
| **`WriteTimeoutMs`** | ミリ秒（例: `1000`） | 送信タイムアウト時間。 |

---

#### `[PROTOCOL]`（通信プロトコル・動作周期設定）

無線機の通信方式やアプリ全体の同期速度を設定します。

| 項目名 | 設定可能な値 | 設定の基準・何に効く設定か |
| --- | --- | --- |
| **`Type`** | `Ascii`, `CIV`, `YaesuBinary` | **`Ascii`**: Kenwood全般、Yaesu新型（FT-991A, FT-710, FTDX10等）<br>

<br>**`CIV`**: Icom機全般（IC-7300, IC-705等）<br>

<br>**`YaesuBinary`**: Yaesu旧型（FT-1000MP, Mark-V等） |
| **`PollIntervalMs`** | ミリ秒（例: `500`, `250`, `100`） | **【今回追加】画面の周波数・Sメーターを取得する周期**。<br>

<br>小さくする（例: `200`）とダイヤル追従が滑らかになりますが、低速ボーレート（4800bps等）では通信詰まりの原因になるため、通常 `250`〜`500` が推奨です。 |
| **`Terminator`** | `;` など | コマンドの終端文字。ASCII CATでは `;` が使われます。 |
| **`FreqDigits`** | `11`, `8` 等 | 周波数コマンドの桁数。Kenwood/Yaesu最新機は通常 `11` 桁です。 |
| **`CivRigAddress`** | 16進数（例: `94`, `A2`） | Icom CI-V専用のアドレス。IC-7300は `94`、IC-705は `A4` など無線機本体設定と合わせます。 |
| **`CivControllerAddress`** | 16進数（通常 `E0`） | コントローラー（PC側）のCI-Vアドレス。 |

---

#### `[COMMANDS]`（コマンドおよびテンプレート定義）

VFO-A / VFO-B に連動したコマンドを定義します。共通ルールとして、**`_A` や `_B` を付けると VFO ごとに異なるコマンド**を実行し、省略すると共通コマンドになります。

##### ① アンテナ設定（共通テンプレート + 個別値方式）

* **共通テンプレート**:
* `ANT_SET_A = AN0{0};`（VFO-A 用のアンテナ切り替え構文。`{0}` にアンテナ番号が入る）
* `ANT_SET_B = AN1{0};`（VFO-B 用のアンテナ切り替え構文。`{0}` にアンテナ番号が入る）


* **個別アンテナ値**:
* `ANT_1 = 1`
* `ANT_2 = 2`
* `ANT_3 = 3`
* `ANT_4 = 4`
※ VFO-A で ANT 1 を押すと `AN01;` が、VFO-B で ANT 1 を押すと `AN11;` が送信されます。



##### ② モード設定

* `MD_SET_A = MD0{0};`（VFO-A用モード設定構文）
* `MD_SET_B = MD1{0};`（VFO-B用モード設定構文）
* `MD_SET = MD{0};`（VFOで共通の場合）
* `MD_GET_A = MD0;` / `MD_GET_B = MD1;`（VFOごとのモード取得）

##### ③ 周波数・VFO・その他

* `FA_GET = FA;` / `FB_GET = FB;`（周波数取得）
* `FA_SET = FA{0:D11};` / `FB_SET = FB{0:D11};`（周波数設定）
* `VFO_A = VS0;` / `VFO_B = VS1;`（VFO選択切り替え）
* `TX_ON = TX1;` / `TX_OFF = TX0;`（PTT制御）
* `SM_GET = SM0;`（Sメーター取得）

---

#### `[MODES]`（モード名とコマンドコードの対応）

画面上のボタン名（LSB, USB, CW 等）と、無線機が解釈するモードコード番号を紐づけます。

```ini
[MODES]
LSB = 1
USB = 2
CW = 3
FM = 4
AM = 5
DATA-USB = C

```

---

#### `[BANDS]`（バンド名とコマンドコードの対応）

画面のバンド選択ドロップダウンと連動します。

* **テンプレートを使う場合**:
```ini
[COMMANDS]
BAND_SET_A = BD0{0};
BAND_SET_B = BD1{0};

[BANDS]
7MHz = 03
14MHz = 05

```


* **直接コマンドを指定する場合**:
```ini
[BANDS]
7MHz = *B03;
14MHz = *B05;

```

### 3. 設定ファイル（.ini）の記述例（Kenwood / Yaesu 新型機向け）

```ini
[SERIAL]
PortName = COM3
BaudRate = 38400
DataBits = 8
Parity = None
StopBits = One
DtrEnable = True
RtsEnable = True
ReadTimeoutMs = 1000
WriteTimeoutMs = 1000

[PROTOCOL]
Type = Ascii
# 画面の更新周期を300msに設定
PollIntervalMs = 300
Terminator = ;
FreqDigits = 11

[COMMANDS]
# 周波数
FA_GET = FA;
FB_GET = FB;
FA_SET = FA{0:D11};
FB_SET = FB{0:D11};

# VFO選択
VFO_A = VS0;
VFO_B = VS1;

# モード（VFO-A / VFO-B 個別テンプレート）
MD_GET_A = MD0;
MD_GET_B = MD1;
MD_SET_A = MD0{0};
MD_SET_B = MD1{0};

# アンテナ（共通テンプレート + 個別値）
ANT_SET_A = AN0{0};
ANT_SET_B = AN1{0};
ANT_1 = 1
ANT_2 = 2
ANT_3 = 3
ANT_4 = 4

# PTT・メーター
TX_ON = TX1;
TX_OFF = TX0;
SM_GET = SM0;
IF_GET = IF;

[MODES]
LSB = 1
USB = 2
CW = 3
FM = 4
AM = 5
DATA-USB = C

[BANDS]
1.9MHz = 01
3.5MHz = 02
7MHz = 03
10MHz = 04
14MHz = 05
18MHz = 06
21MHz = 07
24MHz = 08
28MHz = 09
50MHz = 10
144MHz = 11
430MHz = 12

```
