# アマチュア無線機の制御ソフト
アマチュア無線機（Yaesu, Icom, Kenwood）の制御を GUI 上で行うことができるソフトウェアです。

## 主な機能
* 周波数の取得
* 周波数の変更
* VFO A <-> VFO B の切り替え
* バンドの変更
* モードの変更
* アンテナの変更

---
# RigControlApp 設定ファイル (.ini) 編集マニュアル

本アプリケーションは、設定ファイル（`.ini`）を編集することで Kenwood、Yaesu、Icom を含む多様なアマチュア無線機（リグ）の通信規格やコマンド体系に対応できます。

---

## 1. 設定ファイルの基本構造

設定ファイルはテキスト形式であり、以下の3つの要素で構成されます。

* **セクション（`[セクション名]`）**: 設定項目のグループ。
* **キーと値（`Key = Value`）**: 各機能の設定項目名と設定値。
* **コメント（`#` または `;`）**: 行頭に置くとその行は説明文として処理から除外されます。

---

## 2. 書式指定プレースホルダ（特殊記法）の仕様

`[COMMANDS]` セクションで使われる `{0}` や `{0:D9}` は、アプリ内部の数値や選択値を指定の書式・桁数に変換して埋め込むための変数枠（プレースホルダ）です。

* **`{0}`（単純置換）**:
選択されたコードや数値をそのまま文字列として代入します。
* 設定例: `MD_SET_A = MD0{0};`
* 動作: モードコード `2` が渡された場合、`MD02;` を送信します。

* **`{0:D<桁数>}`（10進数ゼロ埋め）**:
数値を指定された桁数になるよう左側を `0` で埋めて出力します。

* `{0:D11}`: 11桁固定（Kenwood系CAT）。周波数 `7074000` $\rightarrow$ `00007074000`（コマンド: `FA00007074000;`）
* `{0:D9}`: 9桁固定（Yaesu系CAT）。周波数 `14074000` $\rightarrow$ `014074000`（コマンド: `FA014074000;`）
* `{0:D3}`: 3桁固定（AFゲイン・パワー制御等）。数値 `50` $\rightarrow$ `050`（コマンド: `AG0050;`）

## 3. [SERIAL] セクション（シリアル通信設定）

PCとリグ間の物理通信パラメータを定義します。

| キー名 | 設定例 | 設定基準 | 影響 |
| --- | --- | --- | --- |
| **PortName** | `COM3` | デバイスマネージャーで確認したCOMポート番号

 | 接続先シリアルポート

 |
| **BaudRate** | `38400` | リグ本体のCAT/CI-V速度設定値と一致させる

 | 不一致時は通信不能

 |
| **DataBits** | `8` | 通常は `8` を指定

 | データフレーム長

 |
| **Parity** | `None` | 通常は `None`（なし）を指定

 | パリティ検査ビット

 |
| **StopBits** | `One` | 通常 `One`、FT-1000等の旧機は `Two` を指定

 | ストップビット長

 |
| **DtrEnable** | `True` | 仮想COMポートの制御線電源（通常 `True`）

 | CATインターフェースの起動・電源

 |
| **RtsEnable** | `True` | ハードウェアフロー・制御線電源（通常 `True`）

 | 送信制御やインターフェース給電

 |
| **ReadTimeoutMs** | `1000` | 応答待機の上限ミリ秒（標準 `1000`）

 | 通信切断・無応答時のタイムアウト判定

 |
| **WriteTimeoutMs** | `1000` | 送信完了の上限ミリ秒（標準 `1000`）

 | ポート詰まり時のタイムアウト判定

 |

## 4. [PROTOCOL] セクション（プロトコル・ポーリング設定）

通信プロトコルの種類と内部タイマー周期を定義します。

| キー名 | 設定値 | 設定基準 | 影響 |
| --- | --- | --- | --- |
| **Type** | `ASCII`, `CIV`, `YaesuBinary` | リグのメーカー・世代に合わせて指定

 | 使用する通信ドライバーの切り替え

 |
| **Terminator** | `;` | ASCIIコマンド末尾の終端文字（標準は `;`）

 | コマンド区切りの認識

 |
| **FreqDigits** | `11`, `9` | 周波数コマンドの桁数（Kenwood=11, Yaesu=9）

 | 周波数送信時のゼロ埋め桁数

 |
| **CivRigAddress** | `94`, `A4` | Icom機のCI-Vアドレス（16進数表記）

 | Icom機側のパケット受信判定

 |
| **CivControllerAddress** | `E0` | PC側のCI-Vアドレス（通常 `E0`）

 | リグからの応答先アドレス

 |
| **PollIntervalMs** | `500` | 状態取得の監視周期ミリ秒（最小推奨: 50）

 | UI表示の追従速度とPC負荷のバランス

 |

* **Type の選択基準**:
* `ASCII`: Kenwood機全般、Yaesu新世代機（FT-991A, FT-710, FTDX10 等）。
* `CIV`: Icom機全般（IC-7300, IC-7610, IC-705 等）。
* `YaesuBinary`: Yaesu 5バイトバイナリ機（FT-1000, FT-1000MP, Mark-V 等）。
* **PollIntervalMs の目安**:
* `500`: 標準（0.5秒周期。安定性重視）。
* `100`〜`200`: 高速追従（ダイヤル追従性を高めたい場合）。

## 5. [COMMANDS] セクション（送受信コマンド定義）

各UI操作時に送信するコマンドテンプレートを定義します。

### VFO-A / VFO-B 独立コマンドの構造

本アプリは現在選択されているVFO（AまたはB）を判定し、末尾に `_A` または `_B` がついたキーを優先して実行します。

* **モード切替**: `MD_SET_A`, `MD_SET_B`

* **アンテナ切替**: `ANT_SET_A`, `ANT_SET_B`

* **バンド切替**: `BAND_SET_A`, `BAND_SET_B`


### 主なコマンド一覧

| コマンドキー | 内容・用途 | 記述形式の例 |
| --- | --- | --- |
| **FA_GET / FB_GET** | VFO-A / B 周波数取得

 | ASCII: `FA;` / CIV: `03`<br> |
| **FA_SET / FB_SET** | VFO-A / B 周波数設定

 | ASCII: `FA{0:D9};` / CIV: `05`<br> |
| **VFO_A / VFO_B** | アクティブVFOの選択

 | ASCII: `VS0;` / CIV: `07 00`<br> |
| **MD_GET_A / MD_GET_B** | モードの取得

 | ASCII: `MD0;` / CIV: `04`<br> |
| **MD_SET_A / MD_SET_B** | モードの設定（`{0}` にモードコード代入）

 | ASCII: `MD0{0};` / CIV: `06 {0} 01`<br> |
| **ANT_SET_A / ANT_SET_B** | アンテナ端子切替（`{0}` にアンテナコード代入）

 | ASCII: `AN0{0};` / CIV: `12 0{0}`<br> |
| **BAND_SET_A / BAND_SET_B** | バンド切替テンプレート

 | 独自: `BS{0};` / 周波数: `FA{0:D11};`<br> |
| **TX_ON / TX_OFF** | 送信開始(PTT ON) / 受信復帰(PTT OFF)

 | ASCII: `TX1;` / CIV: `1C 00 01`<br> |
| **SM_GET** | Sメーター値の取得

 | ASCII: `SM0;` / CIV: `15 02`<br> |
| **AG_GET / AG_SET** | AFゲイン（音量）の取得・設定

 | ASCII: `AG0;`, `AG0{0:D3};`<br> |
| **IF_GET** | リグ全般状態の一括取得

 | ASCII: `IF;`<br> |
| **YaesuModel** | YaesuBinary専用モデル識別（`MarkV`, `FT-1000`等）

 | 文字列: `MarkV`<br> |

## 6. マッピングセクション

コマンドテンプレートの `{0}` に代入される具体的なパラメータや対応関係を定義します。

### [MODES]（モードマッピング）

画面のボタン名とリグのモード番号を紐付けます。

* **ASCII形式の例**: `LSB = 1`, `USB = 2`, `CW = 3`, `FM = 4`, `AM = 5`, `DATA-USB = 9`
* **CI-V形式の例**: `LSB = 00`, `USB = 01`, `AM = 02`, `CW = 03`, `FM = 05`

### [ANTENNAS]（アンテナマッピング）

画面上のアンテナ番号（`1`〜`4`）とリグの制御番号を紐付けます。

* **1始まりの機種（Kenwood/Yaesu等）**: `1 = 1`, `2 = 2`, `3 = 3`, `4 = 4`
* **0始まりの機種（Icom CI-V/Yaesu 5Byte等）**: `1 = 0`, `2 = 1`, `3 = 2`, `4 = 3`

### [BANDS]（バンドマッピング）

バンドドロップダウンで選択されたバンドに対応するコード、または周波数(Hz)を定義します。
* **パターンA: 独自バンド切替コマンドを使用する場合**
* `BAND_SET_A = BS{0};`（Yaesu）と組み合わせる場合: `7MHz = 03` $\rightarrow$ `BS03;` を送信。
* `BAND_SET_A = 01 {0}`（Icom）と組み合わせる場合: `7MHz = 02` $\rightarrow$ `01 02` を送信。
* **パターンB: 周波数ダイレクト遷移を行う場合（Kenwood等）**
* `BAND_SET_A = FA{0:D11};` と組み合わせる場合: `7MHz = 7074000` $\rightarrow$ `FA00007074000;` を送信。

## 7. 機種別クイックリファレンス
### Kenwood（TS-590, TS-890 等）
* `[PROTOCOL]` セクションで `Type = ASCII`, `FreqDigits = 11` を指定。
* 独自バンドコマンドが無いため、`BAND_SET_A = FA{0:D11};` と各バンドの代表周波数(Hz)を指定。

### Yaesu 新世代機（FT-991A, FT-710, FTDX10 等）
* `[PROTOCOL]` セクションで `Type = ASCII`, `FreqDigits = 9` を指定。
* VFO-A は `MD0` / `AN0`、VFO-B は `MD1` / `AN1` を使用。
* バンド切替は独自コマンド `BAND_SET_A = BS{0};` と `[BANDS]` のBSコード（`00`〜`15`）を使用。

### Icom（IC-7300, IC-705, IC-7610 等）
* `[PROTOCOL]` セクションで `Type = CIV`, `CivRigAddress = 94`（機種設定に合わせる）を指定。
* コマンドは空白区切りの16進数（例: `07 00`）で記述。
* バンド切替は独自コマンド `BAND_SET_A = 01 {0}` と `[BANDS]` のスタッキングレジスタコードを使用。

### Yaesu 5バイトバイナリ機（FT-1000, FT-1000MP, Mark-V）
* `[SERIAL]` セクションで `BaudRate = 4800`, `StopBits = Two` を指定。
* `[PROTOCOL]` セクションで `Type = YaesuBinary` を指定。
* 5バイトの16進数フォーマットでコマンドを記述。
