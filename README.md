# アマチュア無線機の制御ソフト
アマチュア無線機（Yaesu, Icom, Kenwood）の制御を GUI 上で行うことができるソフトウェアです。

## 主な機能
* 周波数の取得
* 周波数の変更
* VFO A <-> VFO B の切り替え
* バンドの変更
* モードの変更
* アンテナの変更


---
## .ini ファイル編集マニュアル
本アプリケーションの `.ini` 設定ファイルは、使用する無線機（リグ）の通信仕様や制御コマンドを定義し、UI（画面表示や操作）とリグの動作を紐付けるための構成ファイルです。

### 書式指定プレースホルダ（特殊な記述）の仕組み

`[COMMANDS]` セクションなどで使われる `{0}` や `{0:D9}` は、アプリ内部の数値や選択値を指定の桁数・書式に変換して埋め込むための変数枠（プレースホルダ）です。

* **`{0}`（単純置換）**:
指定された値やコードをそのまま埋め込みます。


* 例: テンプレートが `AN{0};` で、アンテナ番号が `1` の場合 $\rightarrow$ `AN1;` を送信。




* **`{0:D<桁数>}`（10進数ゼロ埋めフォーマット）**:
数値を指定した全体の桁数になるよう、左側を `0` で埋めて出力します。


* **`{0:D11}`（11桁ゼロ埋め）**: 周波数 `7,074,000 Hz` を渡すと `00007074000` に変換。


* `FA{0:D11};` $\rightarrow$ `FA00007074000;`（Kenwood系CAT）




* **`{0:D9}`（9桁ゼロ埋め）**: 周波数 `14,074,000 Hz` を渡すと `014074000` に変換。


* `FA{0:D9};` $\rightarrow$ `FA014074000;`（Yaesu系CAT）




* **`{0:D3}`（3桁ゼロ埋め）**: ゲイン値 `50` を渡すと `050` に変換。


* `AG0{0:D3};` $\rightarrow$ `AG0050;`

### 各セクション・設定項目の詳細

#### 1. [SERIAL] セクション（シリアルポート通信設定）

PCとリグ（またはUSB-シリアル変換チップ）間の通信パラメータを一致させる設定です。

| 設定項目 | 設定可能な値 | 設定基準・役割 | 影響 |
| --- | --- | --- | --- |
| **PortName** | `COM1` 〜 `COM256` | リグが認識されているデバイスマネージャー上のCOM番号。

 | 接続先の物理ポート。

 |
| **BaudRate** | `4800`, `9600`, `19200`, `38400`, `115200` | 通信速度 (bps)。リグ本体のCAT/CI-V設定と一致させる。

 | 一致しないと文字化け・通信不能。

 |
| **DataBits** | `8`, `7` | 1フレームあたりのデータ長。通常は `8`。

 | 通信プロトコルの同期。 |
| **Parity** | `None`, `Even`, `Odd` | パリティチェック。通常は `None`。

 | 通信エラーチェック。 |
| **StopBits** | `One`, `Two` | ストップビット長。通常 `One`、FT-1000等旧機は `Two`。

 | フレーム区切りの認識。

 |
| **DtrEnable** | `True`, `False` | DTR信号線の電圧をONにするか。通常 `True`。

 | 仮想COMの電源供給・リセット解除。

 |
| **RtsEnable** | `True`, `False` | RTS信号線の電圧をONにするか。通常 `True`。

 | ハードウェアフロー制御・電源供給。

 |
| **ReadTimeoutMs** | `500` 〜 `3000` (ミリ秒) | リグからの応答待機上限時間。標準 `1000`。

 | 応答途絶時のタイムアウト制御。

 |
| **WriteTimeoutMs** | `500` 〜 `3000` (ミリ秒) | 送信完了待機上限時間。標準 `1000`。

 | ポート詰まり時のタイムアウト制御。

 |

---

#### 2. [PROTOCOL] セクション（通信方式・動作周期設定）

リグの制御プロトコル種別や定期通信の挙動を指定します。

| 設定項目 | 設定可能な値 | 設定基準・役割 | 影響 |
| --- | --- | --- | --- |
| **Type** | `ASCII`, `CIV`, `YaesuBinary` | リグの通信方式。

<br>

<br>・`ASCII`: Kenwood / Yaesu新世代機

<br>

<br>・`CIV`: Icom全般

<br>

<br>・`YaesuBinary`: FT-1000 / Mark-V

 | 使用される内部通信ドライバーの切り替え。

 |
| **Terminator** | `;`, `\r`, `\n` | ASCIIコマンド末尾の終端文字（通常 `;`）。

 | リグが1コマンドの終わりを認識するために必須。

 |
| **FreqDigits** | `11`, `9`, `8` | ASCII周波数コマンドの文字桁数（Kenwood=11, Yaesu=9等）。

 | `{0:D<桁数>}` 展開時のデフォルト桁数。

 |
| **CivRigAddress** | `94`, `A4`, `70` 等 (16進数) | Icom CI-V 機種アドレス（例: IC-7300=`94`, IC-705=`A4`）。

 | Icom機が自機宛のパケットか識別する。

 |
| **CivControllerAddress** | `E0` (16進数) | PC（コントローラー）側のCI-Vアドレス。基本は `E0`。

 | リグからの返信先アドレス。

 |
| **PollIntervalMs** | `50` 〜 `2000` (ミリ秒) | **リグから周波数・モード・Sメーターを自動取得する周期**。

 | 数値を小さくすると追従性が向上し、大きくするとCPU・通信負荷が低減。

 |

#### 3. [COMMANDS] セクション（制御コマンド定義）

各操作時にリグへ送受信する具体的なコマンド文字列または16進バイト列（空白区切り）を定義します。

**VFO-A / VFO-B 依存コマンドの使い分け**
リグは現在アクティブなVFO（AまたはB）に応じて異なるコマンドを要求する場合があります。

* **`MD_SET_A` / `MD_SET_B**`: VFO-A / VFO-B に対するモード変更。


* 例（Yaesu）: VFO-Aは `MD0{0};`、VFO-Bは `MD1{0};`



* **`ANT_SET_A` / `ANT_SET_B**`: VFO-A / VFO-B に対するアンテナ端子選択。


* 例（Yaesu）: VFO-Aは `AN0{0};`、VFO-Bは `AN1{0};`



* **`BAND_SET_A` / `BAND_SET_B**`: バンド切り替え時に送信するテンプレート。


* 独自バンド切替コマンド（Yaesu `BS{0};`、Icom `01 {0}`）または周波数遷移（`FA{0:D9};` 等）を指定。





**主なコマンドキー一覧**

* `FA_GET` / `FB_GET`: VFO-A / B 周波数取得コマンド。


* `FA_SET` / `FB_SET`: VFO-A / B 周波数設定テンプレート。


* `VFO_A` / `VFO_B`: VFO-A / B 切り替えコマンド。


* `TX_ON` / `TX_OFF`: 送信（PTT ON）/ 受信（PTT OFF）コマンド。


* `SM_GET`: Sメーター値取得コマンド。


* `AG_GET` / `AG_SET`: AFゲイン（音量）の取得・設定コマンド。


* `YaesuModel`: `YaesuBinary` プロトコル時のみ使用（`FT-1000`, `FT-1000MP`, `MarkV` 等）。



---

#### 4. [MODES], [ANTENNAS], [BANDS] セクション（マッピング定義）

**[MODES]（モード対応表）**
画面上のモード名（ボタン表記）と、リグ側のモード識別コードをマッピングします。

* `USB = 2`（ASCII CATの場合: `MD02;` の `2`）


* `USB = 01`（CI-V / バイナリの場合: 16進数バイト `0x01`）



**[ANTENNAS]（アンテナ番号対応表）**
UIのアンテナ選択肢（`1`, `2`, `3`, `4`）と、リグに送るパラメータをマッピングします。

* `1 = 1`, `2 = 2`（Kenwood / Yaesu ASCII）


* `1 = 0`, `2 = 1`（Icom CI-V / Yaesu 5-Byte などの 0-indexed 指定）



**[BANDS]（バンド対応表）**
バンド選択肢（`1.9MHz`, `7MHz` など）が選ばれたときに送るコードまたは周波数を定義します。

* **独自コマンドを使う場合**:
* Yaesu: `7MHz = 03`（`BAND_SET_A = BS{0};` と組み合わさり `BS03;` を送信）


* Icom: `7MHz = 02`（`BAND_SET_A = 01 {0}` と組み合わさり `01 02` を送信）




* **周波数ダイレクト遷移を行う場合（Kenwood等）**:
* `7MHz = 7074000`（`BAND_SET_A = FA{0:D11};` と組み合わさり `FA00007074000;` を送信）

### 機種別設定の確認ポイント

* **Kenwood（TS-590, TS-890 等）**:
* `Type = ASCII`, `Terminator = ;`, `FreqDigits = 11`

* バンド切替コマンドは無いため、`BAND_SET_A = FA{0:D11};` と `[BANDS]` への周波数(Hz)記述を使用。




* **Yaesu 新世代機（FT-991A, FT-710, FTDX10 等）**:
* `Type = ASCII`, `Terminator = ;`, `FreqDigits = 9`

* VFO-A は `MD0` / `AN0`、VFO-B は `MD1` / `AN1` を使用。


* バンド切替は `BAND_SET_A = BS{0};` と `[BANDS]` のBSコード（`00`〜`15`）を使用。




* **Icom（IC-7300, IC-705 等）**:
* `Type = CIV`, `CivRigAddress = 94`（機種のメニューで確認）


* コマンドはすべて16進数文字列（例: `07 00`, `15 02`）で記述。


* バンド切替は `BAND_SET_A = 01 {0}` と `[BANDS]` のスタッキングレジスタコードを使用。




* **Yaesu 旧世代機（FT-1000, FT-1000MP, Mark-V）**:
* `Type = YaesuBinary`, `BaudRate = 4800`, `StopBits = Two`

* 5バイトの16進数固定フォーマットで記述。
