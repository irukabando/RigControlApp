# アマチュア無線機の制御ソフト
アマチュア無線機（Yaesu, Icom, Kenwood）の制御を GUI 上で行うことができるソフトウェアです。

## 主な機能
* 周波数の取得
* 周波数の変更
* VFO A <-> VFO B の切り替え
* バンドの変更
* モードの変更
* アンテナの変更


---
# Rig Control App 設定ファイル (.ini) 編集マニュアル

本アプリケーションの `.ini` 設定ファイルは、使用する無線機（リグ）の通信仕様や制御コマンドを定義し、UI（画面表示・操作）とリグの動作を紐付けるための構成ファイルです。

---

## 書式指定プレースホルダ（特殊記法）の仕様

`[COMMANDS]` セクションなどで使用される `{0}` や `{0:D9}` は、アプリ内部の数値や選択値を指定の書式・桁数に変換して埋め込む変数枠（プレースホルダ）です。

* **`{0}`（単純置換）**:
指定された値やコードをそのまま埋め込みます。


* 例: コマンドテンプレートが `AN{0};` で、選択アンテナ番号が `1` の場合 $\rightarrow$ `AN1;` を送信。




* **`{0:D<桁数>}`（10進数ゼロ埋めフォーマット）**:
数値を指定した全体の桁数になるよう、左側を `0` で埋めて出力します。


* **`{0:D11}`（11桁ゼロ埋め）**: 周波数 `7074000` (Hz) を渡すと `00007074000` に変換。


* `FA{0:D11};` $\rightarrow$ `FA00007074000;`（Kenwood系CAT）




* **`{0:D9}`（9桁ゼロ埋め）**: 周波数 `14074000` (Hz) を渡すと `014074000` に変換。


* `FA{0:D9};` $\rightarrow$ `FA014074000;`（Yaesu新世代CAT）




* **`{0:D3}`（3桁ゼロ埋め）**: ゲイン値 `50` を渡すと `050` に変換。


* `AG0{0:D3};` $\rightarrow$ `AG0050;`

## [SERIAL] セクション（シリアル通信設定）

PCとリグ（またはUSB-シリアル変換チップ）間の通信パラメータを一致させる設定です。

| 設定項目 | 設定可能な値 | 設定基準・役割 | 影響 |
| --- | --- | --- | --- |
| **PortName** | `COM1` 〜 `COM256` | デバイスマネージャー上のCOM番号

 | 接続先の物理ポート

 |
| **BaudRate** | `4800`, `9600`, `19200`, `38400`, `115200` | 通信速度 (bps)。リグ本体設定と完全一致させる

 | 不一致時は通信不能

 |
| **DataBits** | `8`, `7` | 1フレームのデータ長。通常は `8`<br> | 通信フレーム同期

 |
| **Parity** | `None`, `Even`, `Odd` | 誤り検出符号。通常は `None`<br> | 通信パリティチェック

 |
| **StopBits** | `One`, `Two` | ストップビット長。通常 `One`（FT-1000等は `Two`）

 | データ区切り認識

 |
| **DtrEnable** | `True`, `False` | DTRピンの電圧印加。通常 `True`<br> | 電源供給・通信起動

 |
| **RtsEnable** | `True`, `False` | RTSピンの電圧印加。通常 `True`<br> | フロー制御・電源供給

 |
| **ReadTimeoutMs** | `500` 〜 `3000` | 応答待機上限時間 (ミリ秒)。標準 `1000`<br> | 応答途絶時の待機制御

 |
| **WriteTimeoutMs** | `500` 〜 `3000` | 送信待機上限時間 (ミリ秒)。標準 `1000`<br> | 送信詰まり時の待機制御

 |

## [PROTOCOL] セクション（プロトコル・ポーリング設定）

リグの通信規格や定期通信の挙動を指定します。

| 設定項目 | 設定可能な値 | 設定基準・役割 | 影響 |
| --- | --- | --- | --- |
| **Type** | `ASCII`, `CIV`, `YaesuBinary` | リグの通信方式（詳細は下記参照）

 | 内部ドライバーの切替

 |
| **Terminator** | `;`, `\r`, `\n` | コマンド終端文字。ASCII規格では通常 `;`<br> | 1コマンドの終了認識

 |
| **FreqDigits** | `11`, `9`, `8` | ASCII周波数コマンドの文字桁数

 | 周波数書式の桁数

 |
| **CivRigAddress** | `94`, `A4`, `70` 等 | Icom CI-V 機種アドレス (16進数)

 | 対象リグの個別識別

 |
| **CivControllerAddress** | `E0` (16進数) | PC（コントローラー）側のCI-Vアドレス

 | リグからの返信先識別

 |
| **PollIntervalMs** | `50` 〜 `2000` | 周波数・Sメーター等の自動取得周期 (ミリ秒)

 | UI更新頻度・通信負荷

 |

**Type で選択可能なプロトコル種別**

* **`ASCII`**: Kenwood 機全般、および Yaesu の新世代機（FT-991A, FT-710, FTDX10 等）。


* **`CIV`**: Icom 機全般（IC-7300, IC-7610, IC-705 等）。


* **`YaesuBinary`**: Yaesu の 5バイトバイナリ CAT 機種（FT-1000, FT-1000MP, Mark-V 等）。

## [COMMANDS] セクション（制御コマンド定義）

各操作時にリグへ送信する具体的なコマンド文字列、または16進バイト列（スペース区切り）を定義します。

**VFO-A / VFO-B 独立コマンド**
本アプリでは、現在アクティブなVFO（AまたはB）に応じてコマンドを切り替えて送信します。

* `MD_SET_A` / `MD_SET_B`: VFO-A / VFO-B に対するモード変更コマンド。


* `ANT_SET_A` / `ANT_SET_B`: VFO-A / VFO-B に対するアンテナ切替コマンド。


* `BAND_SET_A` / `BAND_SET_B`: VFO-A / VFO-B に対するバンド切替コマンド。



**主要コマンドキー一覧**

* **`FA_GET` / `FB_GET**`: VFO-A / VFO-B の周波数取得コマンド（例: `FA;` / `FB;`）。


* **`FA_SET` / `FB_SET**`: VFO-A / VFO-B への周波数設定テンプレート（例: `FA{0:D9};`）。


* **`VFO_A` / `VFO_B**`: VFO-A / VFO-B 選択コマンド（例: `VS0;` / `VS1;`）。


* **`TX_ON` / `TX_OFF**`: 送信（PTT ON）/ 受信（PTT OFF）コマンド。


* **`SM_GET`**: Sメーター値取得コマンド。


* **`AG_GET` / `AG_SET**`: AFゲイン（音量）の取得・設定コマンド。


* **`YaesuModel`**: `Type = YaesuBinary` 時の機種判別名（`FT-1000`, `FT-1000MP`, `MarkV` 等）。

## [MODES], [ANTENNAS], [BANDS] セクション（マッピング定義）

UI上のボタンやリストの選択項目と、実際に送信するパラメータ値を紐付けます。

### [MODES]（モード対応表）

画面上のボタン名と、リグ固有のモードコードを定義します。

* ASCII CAT の例: `USB = 2`（`MD_SET_A = MD0{0};` と組み合わさり `MD02;` を送信）


* CI-V の例: `USB = 01`（`06 01 01` を送信）



### [ANTENNAS]（アンテナ対応表）

画面上のアンテナ選択肢（`1`〜`4`）と、リグ側の端子識別コードを定義します。

* 1始まりのリグ（Kenwood / Yaesu ASCII）: `1 = 1`, `2 = 2`

* 0始まりのリグ（Icom CI-V / Yaesu 5-Byte）: `1 = 0`, `2 = 1`


### [BANDS]（バンド対応表）

バンド選択時に送信する**独自バンドコード**、またはコマンド未対応機種用の**代表周波数 (Hz)** を定義します。

* **独自バンド切替コマンドを使用する場合**:
* Yaesu (`BS` コマンド): `BAND_SET_A = BS{0};` に対し `7MHz = 03` と指定 $\rightarrow$ `BS03;` を送信。


* Icom (`01` コマンド): `BAND_SET_A = 01 {0}` に対し `7MHz = 02` と指定 $\rightarrow$ `01 02` を送信。




* **周波数遷移コマンドを使用する場合（Kenwood 等）**:
* `BAND_SET_A = FA{0:D11};` に対し `7MHz = 7074000` と指定 $\rightarrow$ `FA00007074000;` を送信。

## 機種別設定のクイックリファレンス

* **Kenwood（TS-590, TS-890 等）**
* `Type = ASCII` / `Terminator = ;` / `FreqDigits = 11`

* バンド切替は `BAND_SET_A = FA{0:D11};` と `[BANDS]` への周波数(Hz)直接指定を使用。




* **Yaesu 新世代機（FT-991A, FT-710, FTDX10 等）**
* `Type = ASCII` / `Terminator = ;` / `FreqDigits = 9`

* モード・アンテナは VFO-A (`MD0`, `AN0`) と VFO-B (`MD1`, `AN1`) を分離。


* バンド切替は `BAND_SET_A = BS{0};` と `[BANDS]` のBSコード（`00`〜`15`）を使用。




* **Icom（IC-7300, IC-705 等）**
* `Type = CIV` / `CivRigAddress` はリグ本体のCI-Vアドレス（IC-7300は `94`）と一致させる。


* コマンドはスペース区切りの16進数（例: `07 00`, `15 02`）で記述。


* バンド切替は `BAND_SET_A = 01 {0}` と `[BANDS]` のレジスタコードを使用。




* **Yaesu 旧世代機（FT-1000, FT-1000MP, Mark-V）**
* `Type = YaesuBinary` / `BaudRate = 4800` / `StopBits = Two`

* 5バイト固定のバイナリCATプロトコルを使用。
