# RigControlApp - アマチュア無線機 統合CAT/CI-V制御ソフトウェア

## 概要

PCとアマチュア無線機（トランシーバー）をシリアル/USBケーブルで接続し、GUI上からリアルタイムに送受信制御・周波数変更・メーター監視を行うWindows向けデスクトップアプリケーション（WPF / .NET）です。
外部設定ファイル（`.ini`）を切り替えることで、**Kenwood**、**Yaesu（ASCII CAT / バイナリ）**、**Icom（CI-V）** の各社主要リグに対応します。

---

## 主な機能

* **周波数制御**
* VFO-A / VFO-B の周波数をリアルタイム取得・表示。
* メイン表示部の各桁クリック、矢印キー（↑/↓/←/→）、またはマウスホイールによるダイレクト周波数ステップ変更。
* **マルチメーター同時並列表示**
* **Sメーター（SIG）**: 受信信号強度
* **送信出力（PO）**: 送信電力
* **SWR**: アンテナ整合状態（1.0〜3.0+）
* **ALC**: 適正変調入力レベル監視
* 受信（RX）時・送信（TX）時の自動ポーリング切り替えによる通信負荷軽減。
* **送受信（PTT）切り替え**
* 画面上の「RX / TX」トグルボタンによる送受信切り替え。
* リグ実機側で送信（PTTオン）された状態も自動検知してボタン色に反映。
* **アンテナチューナー（ATU）制御**
* 内蔵/外部ATUの ON / OFF 切替および実機ステータスの反映。
* **アンテナ端子切替・状態表示**
* 現在選択されているアンテナ番号（ANT 1〜4等）の自動取得およびドロップダウンからの即時切り替え。
* **モード切替 & バンド切替**
* LSB, USB, CW, FM, AM, DATA-USB などのワンクリック変更。
* 1.9MHz〜430MHz のアマチュアバンド選択。
* **フィルタ帯域幅（Passband Width）調整**
* `.ini` に定義した帯域幅（Hz / kHz）のドロップダウン選択および直接入力設定。
* **動作ログ出力**
* 送受信したコマンドや切替履歴をタイムスタンプ付きで下部ログエリアに常時記録。

## 動作環境

* **OS**: Windows 10 / Windows 11（64-bit）
* **ランタイム**: .NET 8.0 / .NET 10.0 ランタイム（Windows Desktop Runtime）

## 使い方

1. **PCとリグを接続**
* USBケーブルでPCと無線機を接続し、「デバイス マネージャー」でCOMポート番号（例: `COM3`）を確認します。
* 無線機側のMENU設定で、CAT/CI-Vのボーレート（通信速度）やCI-Vアドレスを確認します。


2. **アプリの起動と設定**
* `RigControlApp.exe` を起動します。
* 画面左上の「設定」ドロップダウンから接続する機種の `.ini` ファイルを選択します。
* 「COM」ドロップダウンから接続先のポートを選択します。


3. **接続**
* 「接続」ボタンをクリックすると通信が開始され、インジケーターが緑色に点灯します。
* 現在の周波数・モード・Sメーター・アンテナ番号が自動取得されます。


4. **周波数の変更操作**
* 周波数表示の変更したい桁をクリックして青いマーカー（▼）を合わせ、マウスホイールまたはキーボードの ↑ / ↓ キーで周波数を増減できます。
* ← / → キーで桁移動が可能です。

## 設定ファイル（`.ini`）のカスタマイズ仕様

設定ファイルは `[SERIAL]`, `[PROTOCOL]`, `[COMMANDS]`, `[MODES]`, `[ANTENNAS]`, `[BANDS]`, `[FILTERS]` の各セクションで構成されます。

### 変数置換プレースホルダ

* **`{0}`**: 選択されたコードをそのまま代入（例: `MD_SET = MD{0};` $\rightarrow$ `MD2;`）
* **`{0:D<桁数>}`**: 指定桁数で10進数ゼロ埋め整形（例: `FA{0:D11};` $\rightarrow$ `FA00014074000;`）

### コメントのルール

* 行全体のコメントは行頭に `#` または `;` を記述します。
* コマンドと同じ行の後ろにコメントを書く場合は **必ず `#**` を使用してください（例: `TX_GET = TX; # PTT取得`）。

## トラブルシューティング

| 現象 | 主な原因 | 対処法 |
| --- | --- | --- |
| **接続時に「設定ファイルが見つかりません」と出る**<br> | `.ini` ファイルの配置場所が異なる、または実行パスがずれている。 | `RigControlApp.exe` と同じ階層または `config/` フォルダ内に `.ini` ファイルが存在するか確認してください。 |
| **接続を押しても「タイムアウト」や無反応になる** | ボーレートの不一致、ポート番号違い、DTR/RTSの給電不足。 | リグ本体のCAT速度設定と `.ini` の `BaudRate` が完全一致しているか確認してください。また、`DtrEnable = True`, `RtsEnable = True` に設定されているか確認してください。 |
| **Icom機で周波数やメーターが取得できない** | CI-Vアドレスの不一致。 | リグ本体の「CI-V アドレス」を確認し、`.ini` 内の `CivRigAddress`（例: IC-7300は `94`）を正しく書き換えてください。 |
| **周波数の表示桁がずれる** | `FreqDigits` の桁数不一致。 | Yaesu機等で桁が合わない場合、`.ini` 内の `FreqDigits` を `11`, `9`, `8` のいずれか実機仕様に合わせて変更してください。 |
